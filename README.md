# Скрипт автоматизированной сверки данных (RpaBank & Pindodo)

Данный проект выполнен в рамках тестового задания и предназначен для парсинга, обработки и сверки финансовых отчетов из двух разных систем.

## Основной функционал

### 1. Парсинг данных
Скрипт извлекает информацию из текстовых отчетов:
- `RpaBank_report` — обработка строк со склеенными столбцами.
- `Pindodo_report` — обработка вертикально записанных данных.

### 2. Экспорт в Excel
После обработки данные сохраняются:
- в отдельные Excel-файлы для каждого отчета;
- в итоговый Excel-файл со сверкой.

### 3. Сверка данных
Сопоставление транзакций выполняется по следующим полям:

| RpaBank | Pindodo |
|---|---|
| Local DateTime | Transaction Date |
| Transaction Amount | Transaction Amount |
| Currency | Transaction Currency |
| Card Number | Retrieval Reference Number |
| Terminal ID | Card Acceptor Terminal ID |

Дополнительно выполняется нормализация форматов дат для корректного сравнения.

---

# Требования к среде

Для запуска исходного кода необходим:

- Python 3.9 или выше

Используемые библиотеки:
- `pandas` — обработка данных и работа с Excel
- `loguru` — логирование
- `openpyxl` — генерация Excel-файлов

Все зависимости указаны в `requirements.txt`.

# Инструкция по запуску

## Способ 1. Запуск исполняемого файла

1. Перейдите в папку `dist/`
2. Запустите:
   - `ReconciliationApp.exe` — для Windows
   - `ReconciliationApp` — для macOS

Важно:
- рядом должна находиться папка `data/` с исходными отчетами.

---

## Способ 2. Запуск из исходного кода

### 1. Клонируйте репозиторий

```bash
git clone <repository_url>

2. Установите зависимости
pip install -r requirements.txt

3. Разместите исходные файлы
data/RPA/RpaBank_report.txt
data/PINDODO/Pindodo_report.txt

4. Запустите приложение
python main.py


Результаты работы:

После выполнения программы в папке output/ будут созданы:
RpaBank_report.xlsx — обработанный отчет RPA
Pindodo_report.xlsx — обработанный отчет Pindodo
reconciliation_report.xlsx — итоговый файл сверки
app.log — лог выполнения программы
Структура reconciliation_report.xlsx
Лист Успешные
Содержит записи, найденные в обоих отчетах.
Лист RpaBank_неуспешные
Содержит записи, присутствующие только в RpaBank_report.
Лист Pindodo_неуспешные
Содержит записи, присутствующие только в Pindodo_report.
Особенности реализации
Выполняется нормализация форматов дат перед сверкой.
Ошибки парсинга фиксируются в логах и не прерывают выполнение программы.
Для обработки данных используется pandas.
Для логирования используется loguru.
