# Скрипт автоматизированной сверки данных (RpaBank & Pindodo)

[cite_start]Данный проект выполнен в рамках тестового задания и предназначен для парсинга, обработки и сверки финансовых отчетов из двух разных систем[cite: 1, 5].

## Основной функционал
1.  [cite_start]**Парсинг данных**: Извлечение информации из текстовых файлов со сложной структурой (склеенные столбцы в RPA и вертикальная запись в Pindodo)[cite: 3, 9, 10, 15].
2.  [cite_start]**Экспорт в Excel**: Сохранение результатов обработки каждого отчета в отдельные файлы и создание итогового отчета сверки[cite: 4, 11, 16].
3.  [cite_start]**Сверка данных**: Сопоставление транзакций по пяти ключевым полям[cite: 5, 18]:
    * [cite_start]Дата (с нормализацией форматов)[cite: 20].
    * [cite_start]Сумма транзакции[cite: 21].
    * [cite_start]Валюта[cite: 22].
    * [cite_start]Номер карты / RRN (Card Number из RPA сверяется с Retrieval Reference Number из Pindodo)[cite: 23].
    * [cite_start]ID терминала[cite: 24].

## Требования к среде
Для запуска исходного кода необходим **Python 3.9** или выше.
[cite_start]Основные используемые библиотеки (указаны в `requirements.txt`)[cite: 30, 31, 38]:
* `pandas` — для обработки данных и работы с Excel.
* `loguru` — для расширенного логирования процессов.
* `openpyxl` — движок для генерации Excel-файлов.

## Инструкция по запуску

### Способ 1: Запуск исполняемого файла (без установки Python)
1.  Перейдите в папку `dist/`.
2.  [cite_start]Запустите файл `ReconciliationApp` (для macOS) или `ReconciliationApp.exe` (для Windows)[cite: 34, 37].
    * *Примечание: Исполняемый файл ожидает наличие папки `data/` с исходными отчетами в той же директории.*

### Способ 2: Запуск из исходного кода
1.  [cite_start]Склонируйте репозиторий[cite: 33].
2.  Установите зависимости:
    ```bash
    pip install -r requirements.txt
    ```
3.  Разместите исходные отчеты в папках:
    * `data/RPA/RpaBank_report.txt`
    * `data/PINDODO/Pindodo_report.txt`
4.  Запустите основной скрипт[cite: 37]:
    ```bash
    python main.py
    ```

## Результаты работы
[cite_start]После завершения работы в папке `output/` будут созданы[cite: 25]:
* `RpaBank_report.xlsx` — структурированные данные RPA.
* `Pindodo_report.xlsx` — структурированные данные Pindodo.
* **`reconciliation_report.xlsx`** — итоговая сверка, разделенная на листы:
    * `Успешные`: совпадения в обоих отчетах[cite: 26].
    * [cite_start]`RpaBank_неуспешные`: записи только в RPA[cite: 27].
    * `Pindodo_неуспешные`: записи только в Pindodo[cite: 28].
* [cite_start]`app.log` — подробный лог выполнения программы[cite: 31].

## Особенности и допущения
* [cite_start]**Сверка дат**: Даты в формате `2025-06-25` и `20250625` приводятся к единому стандарту для корректного сопоставления[cite: 39].
* **Логирование**: В случае ошибок парсинга некорректные строки фиксируются в логе с указанием их содержания, но не прерывают работу всей программы[cite: 31, 39].
